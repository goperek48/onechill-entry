One line of horror for make.fun's "One Line, One Chill" bounty ($5, top 10 by judge win rate). A single sentence, under 200 characters, meant to frighten a reader in one breath:

> The night nurse logged my mother's last words at 3am, but my mother died in 2019, and the handwriting in the log is mine.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the sentence to `entry.txt` in the output directory — exactly as written, no trailing newline. The harness default is `/output`.
